# SYSTEM DEPENDENCY: ffmpeg (brew install ffmpeg)
#   Capture goes through ffmpeg's avfoundation input so cameras can be selected
#   by NAME. OpenCV's VideoCapture only takes a positional index, and those
#   indices reshuffle when a webcam or Continuity Camera connects/disconnects —
#   which silently repoints a saved camera at a different physical device.
